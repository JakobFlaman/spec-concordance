# spec-concordance
Process model for AI spec-driven development on OpenSpec: council reviews from six roles, hard quality gates and project templates. Claude Code plugin.

## Contents
- `agents/council-*.md` – six council roles: Product, Architect, Security, QA, Operations, Maintainer.
- `commands/council.md` – `/spec-concordance:council <change-id>` runs the council review.
- `commands/gate.md` – `/spec-concordance:gate <change-id>` checks the hard quality gates.
- `templates/` – project templates for review reports and gate checklists.

# Sicherheit / Security

## Sicherheitslücken melden

Bitte **keine öffentlichen Issues** für Sicherheitslücken. Nutze stattdessen die private Meldung über GitHub: **Security → Report a vulnerability** in diesem Repository.

Wir bestätigen den Eingang innerhalb eines Arbeitstags und melden uns mit einer Einschätzung innerhalb von fünf Arbeitstagen.

## Reporting a vulnerability

Please **do not open public issues** for security problems. Use GitHub's private reporting: **Security → Report a vulnerability** in this repository. We acknowledge within one business day and follow up with an assessment within five business days.

# Beitragen

Danke für dein Interesse. Dieses Projekt wird nach seinem eigenen Vorgehensmodell entwickelt.

## Ablauf

1. **Issue eröffnen** über die Formulare (Fehler oder Wunsch). Bitte nicht direkt mit einem Pull Request starten.
2. Der Maintainer klassifiziert das Issue und legt einen OpenSpec-Change an, oder er lehnt es mit Begründung ab.
3. Nach dem Council-Review kann die Umsetzung als Pull Request erfolgen.
4. Ein PR wird gemergt, wenn das Qualitäts-Gate bestanden ist und der Maintainer freigibt.

## Regeln

- Inhalte zuerst auf Deutsch (Quellsprache). Englische Fassungen werden nachgezogen.
- Ein PR = ein Thema.
- KI-generierte Beiträge sind willkommen. Nenne im PR das Werkzeug und das Modell.
- Mit deinem Beitrag stimmst du zu, dass er unter der MIT-Lizenz des Projekts veröffentlicht wird.

## Sicherheitslücken

Nicht als Issue melden – siehe [SECURITY.md](SECURITY.md).

---

**English:** Please open an issue using the forms first; PRs follow after the council review. Content is authored in German first. AI-generated contributions are welcome – state the tool and model in the PR. Security issues: see SECURITY.md.
